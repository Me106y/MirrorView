# MirrorView

MirrorView 是一个面向求职者的 AI 求职训练网站，帮助你准备简历、分析目标岗位、练习面试，并生成投递所需的求职文案。你可以直接通过网站使用各项工具，不需要了解项目内部实现。

[English](README.md) | 中文

## 通过网站使用

1. 打开已部署的 MirrorView 网站。
2. 在“模型设置”中选择模型服务，填写 API Key、Base URL 和模型名称，然后测试连接并保存。
3. 从首页选择需要的工具，按页面提示填写简历、岗位 JD 或个人经历。
4. 查看 AI 生成的分析、简历、求职信或面试对话结果；支持导出的功能可以保存为 HTML 或 PDF。

模型 API Key 由浏览器端保存并用于调用模型。建议使用临时或额度受限的 Key，并在不再使用时及时撤销。GitHub 登录为可选功能，是否启用取决于网站部署配置。

## 网站功能

### 简历匹配分析

上传 PDF 简历，填写目标岗位和岗位 JD，获取：

- 简历与岗位的匹配度和综合结论；
- 与岗位要求对应的优势、短板和关键缺口；
- 可直接执行的简历优化建议；
- 可在页面中查看并导出的分析报告。

<!-- 截图占位：简历匹配分析结果页面。 -->

### AI 简历生成

通过引导式流程逐步填写目标岗位、个人信息、教育背景、工作或项目经历、技能与证书等内容。系统会结合岗位方向生成简历，并支持：

- 多种简历模板；
- 中文、英文或中英文双版输出；
- 可选个人照片；
- 预览并导出 HTML / PDF 文件。

<!-- 截图占位：简历填写流程和简历预览页面。 -->

### 求职信撰写

输入公司名称、目标岗位 JD 和简历内容，生成针对具体岗位的个性化求职文案。当前支持邮件投递和招聘平台聊天两种场景。

<!-- 截图占位：求职信生成页面。 -->

### 文字模拟面试

在对话页面中输入目标岗位或直接开始回答问题，AI 面试官会结合上下文进行连续追问，适合练习：

- 自我介绍和岗位动机；
- 项目经历与行为面试问题；
- 技术、业务和场景题的表达；
- 回答结构和面试沟通节奏。

### 岗位搜索

岗位搜索入口已经保留，但当前网站版本仍处于占位阶段，尚未接入实际职位数据源和完整的异步搜索流程。

## 本地运行

这部分面向需要自行部署或参与开发的用户。普通使用者只需访问已部署的网站。

### 环境要求

- Python 3.11 或更高版本
- Node.js 20 或更高版本
- npm 10 或更高版本

### 安装依赖

项目只保留一份 Python 依赖清单和一份环境变量模板：

```bash
pip install -r requirements.txt
cd web
npm install
cd ..
```

复制环境变量模板后填写模型配置：

```bash
cp .env.example .env
```

至少需要配置一个模型 API Key。默认示例使用 DeepSeek：

```dotenv
PLATFORM_PROVIDER=deepseek
PLATFORM_MODEL=deepseek-chat
DEEPSEEK_API_KEY=sk-...
```

真实密钥不要提交到 Git。

### 启动服务

在仓库根目录启动后端：

```bash
python -m server.app
```

另开一个终端启动前端：

```bash
cd web
npm run dev
```

默认地址：

- 网站前端：`http://localhost:5173`
- Flask API：`http://localhost:5001`

## 项目状态

当前版本的主要可用功能是简历匹配分析、AI 简历生成、求职信撰写和文字模拟面试。岗位搜索入口暂为后续迭代预留。
